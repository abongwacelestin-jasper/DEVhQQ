Generated by `make secrets` (`infra/scripts/gen-secrets.sh`). Every file here
except this README and `.gitignore` is ignored by git and must never be
committed. Directory mode 0700, files 0640 (see the script header for why).

|---|---|---|

| `minio_root_user`, `minio_root_password` | minio, minio-init | generated |
| `s3_access_key_id`, `s3_secret_access_key` | backend, models, minio-init | generated (app user) |
| `ml_service_token` | backend, models | generated |
| `backup_encryption_key` | `infra/scripts/backup-db.sh` / `restore-db.sh` (host only) | generated — **store a copy off-host** |
| `anthropic_api_key` | models | paste in |
| `smtp_password` | backend | paste in |
| `github_app_private_key`, `github_webhook_secret`, `github_client_secret`, `github_token` | backend | paste in |

`503 integration_unconfigured`).
