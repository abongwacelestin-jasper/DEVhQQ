# Designer

Works design tasks, docs and handoffs. Project and Product `contribute`,
Organization and Repository `view`, no Deployment, Infrastructure or
Administration ([matrix](../concepts/permission-matrix.md)). Demo account:
Inès Moreau (`m9`, renewberry and mirror).

## Daily flow

1. **My work** (`/my-work`) — your tasks.
2. **Projects** (`/projects`) and **Task detail** — create design tasks, move
   them to `review`, comment, add subtasks, log time. As with every
   contributor, someone else (reviewer or manager) moves your task to `done`.
3. **Docs** (`/docs`) — write specs and handover docs; restricted docs are
   visible only to their editors.
4. **Work activity** (`/activity`) — what changed on the tasks you can see.
5. **Messages** (`/messages`) — channels and DMs; attach design files.

Designers do not see Deployments, Incidents, Monitors, Repositories or Team.
